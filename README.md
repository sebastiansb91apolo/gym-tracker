# Gym Tracker

App personal de seguimiento de entrenamientos de gimnasio. Funciona como PWA — se instala en el iPhone como una app nativa.

## Cómo usarla

1. Abre la URL en Safari (en tu iPhone).
2. Toca el botón Share → "Add to Home Screen".
3. Ábrela desde el ícono — corre a pantalla completa.

Tus datos se guardan **localmente en tu dispositivo** (IndexedDB del navegador). No hay servidor, no hay tracking, no hay cuentas. La opción "Exportar datos" en el menú de configuración descarga un JSON de respaldo que puedes guardar en iCloud Drive.
